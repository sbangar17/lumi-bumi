⏱ about 15 min

This is the whole plan in one picture. Each cube talks to a free cloud "post office" (EMQX). Your phone page talks to the same post office, so you can send text, drawings and photos from anywhere, and the cubes also have two buttons for one-press messages.

⚠️
Why a breadboard? The Super Mini has only one GND pin and one 3V3 pin next to each other, but four things need ground (OLED, buzzer, 2 buttons) and two need 3V3. A breadboard's power rails (or a little solder) let several wires share one pin. A half-size breadboard is a few dollars. Without one, you would need to twist and solder wires together.
ℹ️
Two sets of everything. You said you have the parts for both cubes. Build and test cube #1 completely first, then repeat quickly for cube #2.

Install Thonny and put MicroPython on the board

⏱ about 20 min

MicroPython is a tiny version of Python that runs on the ESP32. We install it once; after that you just copy Python files onto the board.

  1. Install Thonny from thonny.org and open it.
  2. Plug the board into your Mac with the USB-C cable (no wiring needed yet). Use a cable that carries data — some charge-only cables will not work.
  3. In Thonny choose Run → Configure interpreter…. In the first drop-down pick MicroPython (ESP32). In "Port" pick the entry that looks like /dev/cu.usbmodem… (or "USB JTAG/serial debug unit").
  4. Click Install or update MicroPython (esptool) (bottom right of that window). Choose the same port, the ESP32-C3 family and the generic ESP32-C3 variant, keep "Erase flash" ticked, then Install. Wait until it says Done.
  5. If Thonny can't find the board: put it in bootloader mode — hold the BOOT button, tap RST, then release BOOT (or hold BOOT while plugging in the cable). Then retry the install (item 4).
  6. Click OK. Unplug and re-plug the board. The bottom panel of Thonny should show >>>.
ℹ️
Prefer the command line? Download the ESP32_GENERIC_C3 .bin from micropython.org/download/ESP32_GENERIC_C3/, then pip install esptool and run esptool --chip esp32c3 --port /dev/cu.usbmodemXXXX erase-flash followed by esptool --chip esp32c3 --port /dev/cu.usbmodemXXXX write-flash -z 0x0 FIRMWARE.bin (older esptool versions spell these erase_flash / write_flash).

Wire up and test the OLED screen

⏱ about 20 min

Unplug USB before wiring. Four wires connect the screen. Match the labels printed on your module and board — module pin order varies, and the diagram below is a guide.

OLED pin→ESP32-C3 Super Mini
GND→GND (via your GND rail)
VCC→3V3 (via your 3V3 rail) — not 5V
SDA→GPIO5
SCL→GPIO6
⚠️
Check the board's own labels. Super Mini boards are very consistent, but clones exist. The pins used in this guide (5, 6, 7 on one side; 3, 4 and 3V3, GND on the other) are chosen to avoid the three "strapping" pins (GPIO2, 8, 9) that can disturb boot. If your silkscreen differs, tell me and I'll adapt it.

Test A — does the board see the screen?

Plug USB in, then in the REPL:

Add the buzzer and test the sound

⏱ about 10 min
Buzzer pin→ESP32-C3
S / I/O / SIG→GPIO7
VCC / +→3V3 rail
GND / −→GND rail
REPL
from machine import Pin, PWM
import time

buz = PWM(Pin(7), freq=1000, duty_u16=0)
for f in (523, 659, 784, 1047):      # C E G C
    buz.freq(f)
    buz.duty_u16(32768)
    time.sleep_ms(250)
buz.duty_u16(0)                      # silence
💡
Too quiet? A 5 V module on 3.3 V is a bit softer. Move its VCC wire to the board's 5V pin (that's USB power). The signal from GPIO7 is still 3.3 V, which most transistor-driven modules accept. Keep this as a last resort and re-test.

Does your module just beep all by itself? Or stay silent?

Passive buzzers need the chip to make the tone (that's what the test does). If you accidentally have an active buzzer, it beeps whenever it just gets power. To check, run:

REPL
from machine import Pin
Pin(7, Pin.OUT).value(1)    # steady voltage. Any sound at all = it's an ACTIVE buzzer
# Pin(7, Pin.OUT).value(0)  # run this to stop it

Sound from that = active buzzer: it only makes one fixed beep, so the melodies would sound the same. Everything else still works.

Create your free EMQX Cloud broker

⏱ about 20 min

This is the "post office". Menu names on websites change a little over time; if a button isn't where I say, look for the closest match.

  1. Go to emqx.com → Cloud → Sign up (email only).
  2. Click New Deployment and choose the Serverless plan. Pick the data-centre region closest to you and your niece.
  3. Confirm it is free before you click Create: the page should show free monthly quotas (1 million session-minutes and 1 GB traffic as of when I checked) and the price as zero.     UsernameUsed by

Make the cube talk to the cloud

⏱ about 15 min

Now prove the board can open a secure connection to EMQX. Run the Wi-Fi test (step 5) again so you're online, then run this. Fill in your own address and the lumi password.

REPL
# Run the Wi-Fi test above FIRST (in the same Thonny session), then this:
from umqtt.simple import MQTTClient
import time

HOST = "xxxxxxxx.ala.emqxsl.com"     # from your EMQX Overview page
USER = "lumi"
PASSWORD = "the-password-you-made"

def make_client():
    try:      # older MicroPython
        return MQTTClient("lb-test", HOST, 8883, USER, PASSWORD, keepalive=60,
                          ssl=True, ssl_params={"server_hostname": HOST})
    except TypeError:   # newer MicroPython
        import ssl
        ctx = ssl.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
        ctx.verify_mode = ssl.CERT_NONE
        return MQTTClient("lb-test", HOST, 8883, USER, PASSWORD, keepalive=60, ssl=ctx)

def got(topic, msg):
    print("GOT:", topic, msg)

c = make_client()
c.set_callback(got)
c.connect()
print("connected to EMQX!")
c.subscribe(b"lumibumi/test")
c.publish(b"lumibumi/test", b"hello from the cube")
time.sleep(1)
c.check_msg()            # should print:  GOT: b'lumibumi/test' b'hello from the cube'
c.disconnect()

✅ Test checklist (tick each one before moving on)

🛑
If this fails, stop here — the full firmware depends on this working. Common causes: MQTTException: 5 or 4 = wrong username/password; OSError -2 or a timeout = wrong address or Wi-Fi down; an SSL error = tell me the exact text, since MicroPython versions differ in how they take the TLS settings.

⏱ about 10 min

You do not need to re-flash anything to change Wi-Fi.

  1. Unplug the cube. Hold both buttons while plugging it in (or boot a cube that has no Wi-Fi saved).

Put it all in the glass cube

⏱ about 1–2 hours
ℹ️
I don't know what kind of glass cube you have (hollow box with a lid, or solid crystal), so treat these as starting ideas and test before gluing anything.
  • Do a dry run first: tape everything in place and check the screen is readable through/against the glass from where you'll sit.
  • Replace loose jumper wires with soldered wires, or a perfboard, for the final build. Cover any bare joins with heat-shrink or tape — nothing metal should touch the other pins.
  • Buttons: mount them where a child's finger can find them. Differences by feel help (one nearer the front, or put a dab of coloured sticker on A).
  • Buzzer: sound is muffled in a sealed cube. Leave a small gap or hole, or mount the buzzer on a face that isn't glass.
  • Heat/power: the electronics draw very little (roughly the same as a night-light bulb at most), but give the cable a notch so the lid sits flat.
  • Solid glass cube: put the OLED under or behind the cube, press it flat with clear tape or a thin layer of clear silicone, and view through the glass. Expect the image to look a little softer.

Troubleshooting

SymptomTry this
Thonny can't find the board / no portTry another USB-C data cable. Enter bootloader mode (hold BOOT, tap RST, release BOOT) and retry the install. Make sure no other program (a serial monitor) has the port open.

Message formats (JSON)

Topics: PREFIX/to/lumi, PREFIX/to/bumi (messages), PREFIX/status/lumi, PREFIX/status/bumi (retained "online"/"offline").

TypeExample
Text (≤300 chars, ASCII){"type":"text","from":"Auntie","text":"Hi!"}
Quick message{"type":"preset","from":"Auntie","id":"love"} — ids: hi, love, miss, night
Image (128×64, 1 bit){"type":"img","from":"Auntie","data":"<base64 of 1024 bytes>"}

The 1024 bytes are in the OLED's own layout: 8 rows of 128 columns, each byte holding 8 vertical pixels with the least significant bit on top. That's why the cube can copy it straight to the screen.

Security notes

  • The cubes connect over TLS (encrypted) but, to keep MicroPython simple, don't verify the server's certificate. That protects against eavesdropping but not a determined impersonator; fine for a family gadget.
  • Wi-Fi passwords and MQTT passwords sit in plain text on the board's flash. Use unique passwords, never reuse your main ones.
  • Anyone with the EMQX address, a valid user and your topic prefix can message the cubes. Keep the prefix secret and change a user's password if a link leaks.
  • Rate: the buttons wait 2 s between sends to prevent flooding.

def clean(s):
    """The OLED font only has plain ASCII, so swap anything else for '?'."""
    return "".join(c if (32 <= ord(c) < 127 or c == "\n") else "?" for c in s)


def wrap(text, width=16):
    lines = []
    for para in text.split("\n"):
        line = ""
        for word in para.split(" "):
            while len(word) > width:
                if line:
                    lines.append(line)
                    line = ""
                lines.append(word[:width])
                word = word[width:]
            if not line:
                line = word
            elif len(line) + 1 + len(word) <= width:
                line += " " + word
            else:
                lines.append(line)
                line = word
        lines.append(line)
    return lines


def draw_icon(name, x, y, s):
    for r, row in enumerate(ICONS[name]):
        for c in range(8):
            if row & (0x80 >> c):
                oled.fill_rect(x + c * s, y + r * s, s, s, 1)

    try:

def wifi_connect(ssid, password, timeout_s=20):
    wlan.active(True)
    txp = getattr(config, "WIFI_TXPOWER", None)
    if txp:
        wlan.config(txpower=txp)
    wlan.connect(ssid, password)
    t0 = ticks_ms()
    while not wlan.isconnected():
        if ticks_diff(ticks_ms(), t0) > timeout_s * 1000:
            return False
        time.sleep_ms(200)
    return True


def unquote(s):
    b = s.replace("+", " ").encode()
    out = bytearray()
    i = 0
    while i < len(b):
        if b[i] == 37 and i + 2 < len(b):
            try:
                out.append(int(b[i + 1:i + 3].decode(), 16))
                i += 3
                continue
            except ValueError:
                pass
        out.append(b[i])
        i += 1
    return out.decode()


def esc(s):
    return s.replace("&", "&amp;").replace("<", "&lt;").replace('"', "&quot;")

def read_request(cl):
    data = b""
    while b"\r\n\r\n" not in data:
        chunk = cl.recv(512)
        if not chunk:
            break
        data += chunk
    head, _, body = data.partition(b"\r\n\r\n")
    need = 0
    for line in head.split(b"\r\n"):
        if line.lower().startswith(b"content-length:"):
            need = int(line.split(b":")[1])
    while len(body) < need:
        chunk = cl.recv(512)
        if not chunk:
            break
        body += chunk
    return head, body


def portal():
    """Open a hotspot + tiny web page so Wi-Fi details can be typed on a phone."""
    ssids = []
    try:
        wlan.active(True)
        for r in wlan.scan():
            n = r[0].decode("utf-8", "ignore")
            if n and n not in ssids:
                ssids.append(n)
    except Exception as e:
        print("scan failed:", e)
    nets = "".join('<option value="%s">' % esc(n) for n in ssids[:15])

    ap_name = "LumiBumi-Setup"
    ap = network.WLAN(network.AP_IF)
    ap.active(True)
    try:
        ap.config(essid=ap_name, security=0)
    except Exception:
        ap.config(essid=ap_name, authmode=0)
    status("WiFi setup", "Join WiFi:", ap_name, "Open 192.168.4.1")

    srv = socket.socket()
    srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    srv.bind(("0.0.0.0", 80))
    srv.listen(2)
    page = PORTAL_HTML.replace("@NAME@", NAME.capitalize()).replace("@NETS@", nets)
    while True:
        cl, _ = srv.accept()
        try:
            head, body = read_request(cl)
            if head.startswith(b"POST /save"):
                form = {}
                for pair in body.decode().split("&"):
                    k, _, v = pair.partition("=")
                    form[k] = unquote(v)
                with open("wifi.json", "w") as f:
                    json.dump({"ssid": form.get("ssid", ""), "password": form.get("pw", "")}, f)
                cl.sendall(b"HTTP/1.0 200 OK\r\nContent-Type: text/html\r\nConnection: close\r\n\r\n"
                           b"<h2>Saved! Restarting...</h2>")

                status("Saved!", "Restarting...")

                machine.reset()
            cl.sendall(b"HTTP/1.0 200 OK\r\nContent-Type: text/html\r\nConnection: close\r\n\r\n"
                       + page.encode())
        except Exception as e:
            print("portal error:", e)
        finally:

    cid = "lumibumi-" + NAME

def on_message(topic, msg):
    global peer_online
    if topic.decode() == T_PEER_STATUS:
        peer_online = (msg == b"online")
        return
    if len(inbox) < 5:
        inbox.append(msg)


def connect_all():
    """Block until Wi-Fi and MQTT are both up. Retries forever."""
    global client, link_bad
    if client:
        try:
            client.sock.close()
        except Exception:
            pass
        client = None
    ssid, password = load_wifi()
    while True:
        if not wlan.isconnected():
            status("Joining WiFi", ssid[:16])
            if not wifi_connect(ssid, password):
                status("WiFi not found", "retrying...")
                time.sleep(5)
                continue
        status("Connecting", "to the cloud")
        try:
            c = make_client()
            c.set_callback(on_message)
            c.set_last_will(T_STATUS, b"offline", retain=True)
            c.connect(clean_session=False)
            c.subscribe(T_IN, qos=1)
            c.subscribe(T_PEER_STATUS)
            c.publish(T_STATUS, b"online", retain=True)
            client = c
            link_bad = False
            return
        except Exception as e:
            print("cloud connect failed:", e)
            status("Cloud failed", "retrying...")
            time.sleep(5)

def handle_inbox():
    global unread
    while inbox:
        raw = inbox.pop(0)
        try:
            m = json.loads(raw)
            kind = m.get("type")
            sender = clean(str(m.get("from", PEER.capitalize())))[:11] or PEER.capitalize()
            if kind == "text":
                text = clean(str(m.get("text", "")))[:300]
                if not text.strip():
                    continue
                lines = wrap(text)
                pages = [lines[i:i + 5] for i in range(0, len(lines), 5)]
                wake()
                set_view(kind="text", sender=sender, pages=pages, i=0,
                         flip=ticks_add(ticks_ms(), config.PAGE_MS))
                play(MELODY_TEXT)
            elif kind == "preset":
                pid = m.get("id")
                if pid not in PRESETS:
                    continue
                wake()
                set_view(kind="preset", id=pid, sender=sender)
                play(MELODY_PRESET)
            elif kind == "img":
                data = binascii.a2b_base64(m["data"])
                if len(data) != 1024:
                    continue
                wake()
                set_view(kind="image", data=data)
                play(MELODY_IMAGE)
            else:
                continue
            unread = True
        except Exception as e:
            print("bad message:", e)
        gc.collect()

def poll_buttons():
    """Short press = preset, long press (~1 s) = second preset, both held = mute."""
    global both_since, swallow, unread
    now = ticks_ms()
    down = [buttons[0].value() == 0, buttons[1].value() == 0]

    if down[0] and down[1]:
        if both_since is None:
            both_since = now
        elif not swallow and ticks_diff(now, both_since) > 1500:
            swallow = True
            wake()
            toggle_mute()
        for i in (0, 1):
            if held[i] is None:
                held[i] = now
        return
    both_since = None

    for i in (0, 1):
        if down[i]:
            if held[i] is None:
                held[i] = now
        elif held[i] is not None:
            dur = ticks_diff(now, held[i])
            held[i] = None
            if swallow or dur < 40:
                continue
            if wake():          # first press only wakes the screen
                continue
            unread = False
            long_press = dur >= 800
            if i == 0:
                send_preset(config.PRESET_A_LONG if long_press else config.PRESET_A)
            else:
                send_preset(config.PRESET_B_LONG if long_press else config.PRESET_B)
    if not down[0] and not down[1]:
        swallow = False

def housekeeping(now):
    global beat, last_beat, unread, asleep
    kind = view["kind"]
    if asleep:
        return
    if kind == "text" and len(view["pages"]) > 1 and ticks_diff(now, view["flip"]) >= 0:
        view["i"] = (view["i"] + 1) % len(view["pages"])
        view["flip"] = ticks_add(now, config.PAGE_MS)
        redraw()
    elif kind == "idle":
        if ticks_diff(now, last_beat) > 1000:
            beat = not beat
            last_beat = now
            redraw()
    elif ticks_diff(now, view_since) > config.MSG_HOLD_MS:
        unread = False
        set_view(kind="idle")
    if ticks_diff(now, last_activity) > config.SLEEP_AFTER_MS:
        oled.poweroff()
        asleep = True

# MicroPython SSD1306 OLED driver, I2C interface (from the official MicroPython drivers).
from micropython import const
import framebuf

SET_CONTRAST = const(0x81)
SET_ENTIRE_ON = const(0xA4)
SET_NORM_INV = const(0xA6)
SET_DISP = const(0xAE)
SET_MEM_ADDR = const(0x20)
SET_COL_ADDR = const(0x21)
SET_PAGE_ADDR = const(0x22)
SET_DISP_START_LINE = const(0x40)
SET_SEG_REMAP = const(0xA0)
SET_MUX_RATIO = const(0xA8)
SET_IREF_SELECT = const(0xAD)
SET_COM_OUT_DIR = const(0xC0)
SET_DISP_OFFSET = const(0xD3)
SET_COM_PIN_CFG = const(0xDA)
SET_DISP_CLK_DIV = const(0xD5)
SET_PRECHARGE = const(0xD9)
SET_VCOM_DESEL = const(0xDB)
SET_CHARGE_PUMP = const(0x8D)


class SSD1306(framebuf.FrameBuffer):
    def __init__(self, width, height, external_vcc):
        self.width = width
        self.height = height
        self.external_vcc = external_vcc
        self.pages = self.height // 8
        self.buffer = bytearray(self.pages * self.width)
        super().__init__(self.buffer, self.width, self.height, framebuf.MONO_VLSB)
        self.init_display()

    def init_display(self):
        for cmd in (
            SET_DISP,  # display off
            SET_MEM_ADDR, 0x00,  # horizontal addressing
            SET_DISP_START_LINE,
            SET_SEG_REMAP | 0x01,  # column 127 mapped to SEG0
            SET_MUX_RATIO, self.height - 1,
            SET_COM_OUT_DIR | 0x08,  # scan from COM[N] to COM0
            SET_DISP_OFFSET, 0x00,
            SET_COM_PIN_CFG, 0x02 if self.width > 2 * self.height else 0x12,
            SET_DISP_CLK_DIV, 0x80,
            SET_PRECHARGE, 0x22 if self.external_vcc else 0xF1,
            SET_VCOM_DESEL, 0x30,  # 0.83 * Vcc
            SET_CONTRAST, 0xFF,  # maximum
            SET_ENTIRE_ON,  # output follows RAM contents
            SET_NORM_INV,  # not inverted
            SET_IREF_SELECT, 0x30,  # enable internal IREF during display on
            SET_CHARGE_PUMP, 0x10 if self.external_vcc else 0x14,
            SET_DISP | 0x01,  # display on
        ):
            self.write_cmd(cmd)
        self.fill(0)
        self.show()

    def poweroff(self):
        self.write_cmd(SET_DISP)

    def poweron(self):
        self.write_cmd(SET_DISP | 0x01)

    def contrast(self, contrast):
        self.write_cmd(SET_CONTRAST)
        self.write_cmd(contrast)

    def invert(self, invert):
        self.write_cmd(SET_NORM_INV | (invert & 1))

    def show(self):
        x0 = 0
        x1 = self.width - 1
        if self.width != 128:
            # narrow displays use centred columns
            col_offset = (128 - self.width) // 2
            x0 += col_offset
            x1 += col_offset
        self.write_cmd(SET_COL_ADDR)
        self.write_cmd(x0)
        self.write_cmd(x1)
        self.write_cmd(SET_PAGE_ADDR)
        self.write_cmd(0)
        self.write_cmd(self.pages - 1)
        self.write_data(self.buffer)


class SSD1306_I2C(SSD1306):
    def __init__(self, width, height, i2c, addr=0x3C, external_vcc=False):
        self.i2c = i2c
        self.addr = addr
        self.temp = bytearray(2)
        self.write_list = [b"\x40", None]  # Co=0, D/C#=1
        super().__init__(width, height, external_vcc)

    def write_cmd(self, cmd):
        self.temp[0] = 0x80  # Co=1, D/C#=0
        self.temp[1] = cmd
        self.i2c.writeto(self.addr, self.temp)

    def write_data(self, buf):
        self.write_list[1] = buf
        self.i2c.writevto(self.addr, self.write_list)

function wrap(text, width = 16) {
  const lines = [];
  for (const para of text.split("\n")) {
    let line = "";
    for (let word of para.split(" ")) {
      while (word.length > width) {
        if (line) { lines.push(line); line = ""; }
        lines.push(word.slice(0, width)); word = word.slice(width);
      }
      if (!line) line = word;
      else if (line.length + 1 + word.length <= width) line += " " + word;
      else { lines.push(line); line = word; }
    }
    lines.push(line);
  }
  return lines;
}

}

  const s = loadSettings();
  if (!client || !client.connected) { toast("Not connected yet — check Settings"); return; }
  const from = name(), to = $("target").value;
  let msg, summary;
  if (mode === "text") {
    const text = cleanText($("msg").value).trim();
    if (!text) { toast("Type a message first"); return; }
    msg = { type: "text", from, text }; summary = text;
  } else if (mode === "quick") {
    msg = { type: "preset", from, id: quickPick }; summary = ICONS[quickPick].label;
  } else {
    if (!px.some(v => v)) { toast("The picture is empty"); return; }
    msg = { type: "img", from, data: b64(pack()) };
    const c = document.createElement("canvas"); c.width = W; c.height = H; paint(c, px); summary = c;
  }
  client.publish(s.prefix + "/to/" + to, JSON.stringify(msg), { qos: 1 }, err => {
    if (err) { toast("Couldn't send: " + err.message); return; }
    toast("Sent to " + (to === "lumi" ? "Lumi" : "Bumi") + " ✓");
    addLog("You → " + to, summary);
    if (mode === "text") $("msg").value = "";
    updatePreview();
  });
}
$("send").onclick = send;
